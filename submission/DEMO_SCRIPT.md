# 演示视频拍摄脚本（人工配音版）

> 目标时长 **2 分 30 秒 ~ 3 分钟** · 分辨率 1440×900 或 1920×1080 · 建议 25/30fps
> 用途：作品表单「使用说明或录屏」「讲解录屏」两栏
> 已有自动录制的无声版：`demo-walkthrough-captioned.mp4`（带字幕）／`demo-walkthrough.mp4`（无字幕）

---

## 一、录制前准备（5 分钟）

1. **先起在线服务**，让画面里出现「在线 MCP」和券的「（实时）」标记：
   ```bash
   cd <项目目录>
   echo "MCD_MCP_TOKEN=<你的 Token>" > .env    # 变量名以 README 为准
   python server.py
   ```
   浏览器打开 `http://127.0.0.1:4317/`，顶部显示**在线 MCP** 即成功。
2. 浏览器**全屏（F11）**，关掉书签栏，窗口 1440×900 以上。
3. 录屏范围**只录浏览器内容区**，不要录到桌面、任务栏、微信、文件夹路径。
4. 首次打开会弹引导页——**保留这个镜头**（这是功能，不是干扰）。

## 二、隐私红线（录制前逐条检查，务必遵守）

| 绝对不能出现 | 说明 |
|---|---|
| **Token 字符串** | 不打开 `.env`、不打开终端历史、不切到编辑器；顶部状态条只显示「在线 MCP」不含 Token |
| **终端窗口** | 若必须展示 `python server.py`，只拍「运行中」一行，**先清屏并 cd 到无用户名的目录** |
| **本地文件路径 / 用户名** | 用 `http://127.0.0.1:4317/` 打开，**不要用 `file:///D:/Users/...`**（地址栏会暴露用户名） |
| **手机号 / 微信 / 姓名** | 拆单成员名用「成员A / 成员B」，若页面已显示这类字样，先改成通用称呼 |
| **门店具体信息** | 画面出现门店名/地址属官方公开数据可以保留；但不要出现你自己的收货地址、手机号 |
| **浏览器账号 / 头像** | 用无痕窗口，或退出账号 |

> 已核查：当前版本页面**不含任何用户凭证**，`check_release` 每次发布都会扫 Token/密钥/私钥/外链域名；券图与商品图均为官方 CDN。

## 四、口播要点（人工录制时容易念错的地方）

- **「套餐子项」**：是「从整份套餐里只买其中某一件」，不是「换配菜」——官方不支持改配，页面也写明这一点。
- **「按券拆单」**：要说「按**券的张数**拆单」，不要说「按人拆单」。
- **「预演 / 估算」**：凡是离线数据、券收益，一律念「预演」「估算」，别念成「实算」。
- 不要念「AI 大模型」「智能推荐」这类空词，念具体动作。
