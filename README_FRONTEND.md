# 麦麦搭配所

> **这一顿吃什么，照着你的胃口来。**

麦麦搭配所是一款为聚餐和日常点餐设计的麦当劳套餐推荐网页。用户可以用自然语言说清人数、预算、忌口和想吃的感觉，也可以通过控件逐项调整。页面读取门店的麦当劳官方 MCP 数据快照，给出三种个性化组合：省钱聚餐、低卡高蛋白、新品活动尝鲜。每份方案都能展开查看热量与官方营养明细，并生成一份带到官方小程序或 APP 的点单清单。

## 体验重点

- **像和店员说话一样输入**：理解人数、预算区间、无限预算、目标与忌口；没识别到的目标会明确提示，不假装听懂。
- **一次给出三种搭法**：省钱、低卡高蛋白、新品尝鲜固定呈现，方便比较和勾选。
- **把食物放到第一眼**：暖奶油底色、麦当劳红与金色，加深棕色菜单广告板；大图和大价格突出官方菜单商品。
- **活动来源说清楚**：官方活动日历标“官方活动”；优惠券标“可领券”；菜单标签标“菜单上新”或“菜单活动价”。三种来源各自展示。
- **菜单时段可切换**：顶部在下午茶与夜市快照间切换；切换时广告板、门店数据和推荐同步刷新，已选方案清空，原条件自动重跑。
- **数字不编造**：价格、热量与营养直接显示服务层结果；营养未知写“官方未提供，未估算”，部分数据的合计标明为下限。
- **断网也能演示**：页面由本地 HTML、CSS、JavaScript、官方菜单快照和本地图片组成，双击 `index.html` 即可打开，不需要启动服务器。

## 打开方式

1. 保持整个目录结构完整，尤其不要移动 `data/`、`img/`、`engine.js` 和 `service.js`。
2. 双击本目录中的 `index.html`。
3. 在左侧输入需求或选择示例，点击“给我搭三份”。勾选方案后可以算官方快照价格或生成点单清单。

运行时读取构建期生成的 MCP 快照，不连接 GPT 或 WorkBuddy 运行时；CSP 的 `connect-src 'none'` 禁止数据接口联网。商品图优先读取随包的 `img/` 本地素材；图片加载失败时按契约尝试官方图片源，最终使用服务层提供的兜底图。离线展示的正常路径全部使用本地商品和活动图片。

顶部时段选择器使用 `McAdvisor.listSlots()` 自动列出已载入的快照。当前交接包包含下午茶与夜市数据；新时段快照加入后，只要在 HTML 中按顺序引入相应数据脚本，服务接口即可发现它。切换时会创建新的服务实例，因此旧方案 ID 和选择会立即作废，并基于最近一次的查询重新推荐。

## 数据与文件归属

- `index.html`、`style.css`、`app.js`：前端结构、视觉和交互。
- `data/menu_data.js`、`data/menu_data_night.js`、`data/campaigns.js`、`img/`：WorkBuddy 构建期拉取的真实 MCP 快照与官方图片。
- `engine.js`、`service.js`：WorkBuddy 提供的决策引擎与服务接口；前端只调用 `McAdvisor.getService()`。

前端不计算菜品价格、优惠、人均金额、热量或营养，不连接 MCP，不读取 Token，不执行下单或支付。优惠券可以在券箱查看并加入配餐描述；领取、核销和最终适用范围以官方小程序或 APP 为准。

|---|---|---|
| 0:00–0:25 | 首屏停在红金暖色横向布局；展示右侧商品近景、价格、快照时间和时段选择器。 | “菜单、活动和图片来自麦当劳官方 MCP 快照；现在可以在下午茶和夜市菜单间切换。” |
| 0:20–0:45 | 点击示例需求，再改成“3个人、100元以内、不吃辣、想尝鲜”；展示自然语言输入与预算/忌口控件。 | “用户可以随口描述，也可以把人数、预算和忌口细化。” |
| 0:45–1:15 | 点击“给我搭三份”，展示加载与三张个性化方案卡。 | 依次展示省钱、低卡高蛋白、新品尝鲜，并说明总价、人均、原价与节省金额来自服务返回值。 |
| 1:15–1:40 | 展开“看这顿热量”和“看营养成分”。 | 展示整顿与人均热量、分菜品明细、蛋白质/脂肪/碳水/钠/钙；指出未知项不估算、部分合计是下限。 |
| 1:40–2:00 | 勾选方案，点击“算这一单”，再生成并复制官方小程序清单。 | “这是点单参考清单，不会替用户提交订单；费用以官方结算为准。” |
| 2:00–2:20 | 打开左上方优惠券箱，展示券图与“加入配餐偏好”；关闭后点击右侧新品或活动箭头。 | 区分“可领券”“官方活动”“菜单上新/活动价”，不混称活动。 |

| 2:35–2:45 | 展示底部数据说明。 | “偏好仅保存在本机。最终领券和下单都在官方小程序或 APP 完成。” |

## 展示时的准确说法

- 方案排序固定为“省钱 → 低卡高蛋白 → 新品尝鲜”，不代表价格由低到高。
- 这是某次构建时取得的官方菜单、活动和优惠快照，不是实时刷新页面。
- 组合餐的部分营养由官方套餐默认子项数据汇总；服务层标注为下限时，页面保留该说明。
- 今日活动日历、菜单商品标签和可领优惠券是不同来源，页面分别标注。
