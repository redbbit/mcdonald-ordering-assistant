GET STARTED
        
这是什么，怎么用

        
自然语言点餐助手 · 菜单与价格来自麦当劳官方 MCP · 页面不代下单

      

      
    


    

      

        
① 它不是聊天机器人

        
你给一句自然语言，它从当前时段的官方菜单里，配出三种吃法：省钱聚餐、低卡高蛋白、新品尝鲜。每一分钱和每一大卡都能追到官方出处。

      


      

        
② 随口说就行，四类信息顺序随意

        
    
          
  • 几人　3个人 / 我们仨 / 四个人
    • 
          
  • 预算　100块以内 / 80到120 / 预算不限
    • 
          
  • 忌口　不吃辣 / 忌牛肉 / 不要乳制品
    • 
          
  • 想吃　我要吃炸鸡 / 来一份薯饼 / 想吃麦辣鸡腿堡
    • 
        

      


      

        
③ 配完你能拿到

        
    
          
  • 三版方案 + 顶部「我理解成了」复述，解析不是黑箱
    • 
        
  • 每版的热量与官方营养成分（可展开看）
    • 
          
  • 套餐 vs 拆开单点的四维对比：价格 / 热量 / 蛋白质 / 口味匹配
    • 
          
  • 多人分账 + 分人用券，券账本一行一张记去向
    • 
        

      


      

        
④ 它不会做的事

        
    
          
  • 不下单——只给清单，核销请到麦当劳小程序 / APP
    • 
          
  • 官方没给的数据写「官方未提供」，不估算、不编造
    • 
          
  • 离线下价格是快照，标「离线预演」而不是绿色「已校验」
    •

        详细教程与常见报错
        
① Token 从哪来

        
麦当劳 MCP 的访问凭证，绑定你自己的麦当劳账号。本工具读到的券、门店、价格，全部属于这个账号——所以「别人账号里的券」它读不到。

        
② .env 长什么样

        
MCD_MCP_TOKEN=<你的 Token 粘在这里>

        
放在 server.py 同目录，文件名就叫 .env（不是 .env.txt）。

        
③ 常见报错

        
    
          
  • 打开还是离线预演：说明双击了 index.html，改用 http://127.0.0.1:4317/ 打开。
    • 
          
  • 提示找不到 Token / 401：.env 存成了 txt，或 Token 已过期。
    • 
          
  • 端口被占：4317 已被别的进程占用，关掉旧进程再启动。
    • 
          
  • 能开页面但拿不到数据：本机到官方网络不通时会自动降级为离线预演，不会假装有数据。
    • 
        

        
④ 安全边界

        
Token 只写在你本地 .env，不进前端代码、不进仓库、不经过第三方；发布检查每次都会扫一遍。

      

    

    

      在线模式只读取与比价，不会替你下单。
